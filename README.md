# E-Learning_data_analytics_Advanced_Excel
Advanced Excel based Data Analytics Project - Analyzing E-Learning Data Usage
## Project Overview
This project analyzes e-learning usage and learner performance using Microsoft Excel. 
It focuses on engagement, completion, session activity, and participation metrics.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts & Dashboards
- Macro Recording for Page Refresh
- VBA (Macro for PDF export)

## Key KPIs
- Completion Rate
- Engagement Score
- Session Duration
- Quiz Participation
- Assignment Submission

## Features
- Interactive Excel dashboard
- Slicers for filtering
- Automated PDF export using VBA
- Professional visualizations

## Files Included
- Excel dashboard (.xlsm)
- Dashboard PDF
- Project report
- Presentation slides
